# Telco Customer Churn Prediction

Predicting customer churn using the Telco Customer Churn dataset (7,043 customers).
Goal: identify customers likely to leave so the business can take retention action.

## Status
🚧 In progress

## Started
2026-08-28

## Dataset
- 7,043 customers
- 21 features (tenure, contract type, monthly charges, services, etc.)
- Target: Churn (Yes/No)

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn (Logistic Regression / Random Forest / XGBoost)
- Matplotlib, Seaborn (visualization)

## What I learned
- EDA on customer data
- Feature engineering (tenure groups, service counts)
- Handling categorical variables
- Model evaluation (accuracy, precision, recall, F1, ROC-AUC)
